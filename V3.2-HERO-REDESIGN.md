# Almarah Foundation V3.2 — Page-hero redesign

A visual-only release. No routes, controllers, database, payment or admin code was touched.

## What changed
Every public page title/hero now shares one design system, built only from the
existing brand palette (wine `#6B0F35`, rose `#A92D63`, gold `#F2C200`, blush `#FDF5F8`)
and existing fonts (Manrope + Open Sans):

* Aurora wine→rose background with gold and rose glows
* Fading dot-grid and concentric ripple rings
* Curved bottom edge that blends into the next section
* Glass eyebrow chip, large title with gold-gradient accent words, soft subtitle, glass badges
* Gentle entrance animation (disabled automatically for `prefers-reduced-motion`)
* Fully responsive (checked at 1440 px and 390 px)

## Editing copy
The new CEO / Chairperson / E-Book hero text is set in the `$hero = [...]` array at the
top of each of those three page files.

## Rollback
Remove the `hero-v32.css` link from `layouts/public.php` to return to the V3.1 look
(the added eyebrow chips would then render as plain text).
